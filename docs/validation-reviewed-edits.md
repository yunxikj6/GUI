# 开发版验收：续聊、修改审批和草稿恢复

在 Linux 开发机上，最终版本的 55 项回归全部通过，耗时 50.514 秒，零跳过。其中 17 项实际运行 Chromium，3 项使用已安装的 Codex CLI。[完整测试输出](measurements/regression-reviewed-edits.txt)

## 可复现的入口

在仓库根目录运行 `python3 -m unittest discover -s tests -v`。浏览器用例使用 Playwright 和 Chromium。原生模型 CLI 用例还需将 `codex` 加入 PATH。运行原生 CLI 用例时，测试会创建临时用户目录、Git 项目和监听回环地址的 Responses 服务。它使用固定回复核对实际 CLI 协议和文件写入，无需模型账户。

| 场景 | 验收动作及观察 |
| --- | --- |
| Codex 续聊 | 工作台提交首问，拿到回复后继续追问。原生 CLI 的第二次模型请求同时含有首问、首答和追问。两轮只发起两次模型请求，使用同一线程。CLI 的两轮记录均为只读沙箱和禁止提权审批。 |
| 请求或回执丢失 | 在真实浏览器丢弃已被服务端接收的提交回执，再刷新、重试。请求返回已落库的任务。独立 HTTP 检查中，两次重启启动器后，两轮共 8 条事件可逐条重放。 |
| 审核文件修改 | 提案绑定路径及生成时的内容摘要。审核前核对原文件字节，批准后核对工作区文件及 Git 差异。拒绝和过期版本均保留当前磁盘内容。只增加末尾换行也会在审核差异中标出。 |
| 重复审批 | 并发批准同一提案，以及模拟写文件后、提交数据库前退出。恢复后读取已生效的决定。另一次实验在成功批准后继续编辑文件，再重试同一批准，后写入的内容得以保留。 |
| 文件草稿 | 输入中文、刷新同一标签页，在云机未连接时继续编辑多份草稿。重连后核对原始版本。保存已生效但客户端未收到回执时，恢复已提交的版本及此后输入的文字。 |
| 行尾和输入位置 | 在包含 CRLF、LF、CR 的文件中输入中文并保存，按字节检查未修改区域与相邻新行。浏览器回归检查合成输入后的光标位置。 |
| 同一端口切换项目 | 在 A 修改 README，再让同一启动器地址服务另一个同名项目 B。旧页面的保存被拒绝，两份磁盘文件保持原样。B 离线时也只呈现自己的编辑状态。切回 A 后可找回草稿。 |
| 旧版数据 | 在 0.1 的 SQLite 结构中创建任务和中文事件，升级后并发读取，核对任务 ID、事件内容和游标。旧临时会话保留历史输出。 |

## InstaBox 实测

通过本机回环 HTTP 启动器和 InstaBox 官方 HTTPS API，Chromium 在独立云端 Git 项目中实际打开文件、编辑中文、刷新、保存，并在 Git 差异中读到新增行。云端项目检查产生 9 条事件，以原请求重试返回了相同的任务 ID。该实例提供 Codex CLI 0.160.0、Claude Code 2.1.288 和 Git 2.47.3。

在该实例的临时源码副本运行了文件服务、任务、提案、HTTP 桥接和原生 Codex 五组回归，共 32 项通过。另有一项依赖 Bubblewrap 的系统配置模拟因云机缺少该程序而跳过。本机分别用 Codex 0.160.0 和 0.172.0-alpha.2 通过了这项模拟。

真机测试还发现，忽略 Codex 用户配置后，实例预装的系统级 MCP 工具仍会进入模型请求。修复后，单文件提案为本次调用关闭这些服务并复核生效结果。用同一台云机重新生成建议，回环模型服务实际收到的工具列表为空。原生 CLI 返回结构化建议，审批前文件字节保持原样，批准后文件及 Git 差异与建议一致。

对云机中两个真实模型 CLI 分别提交了只读请求。两者均返回模型账户认证失败，工作台显示对应的失败原因。开发机的 Codex CLI 0.172.0-alpha.2 在真实服务认证刷新时也收到 HTTP 401。在线模型的回答质量和成功延迟仍待使用有效模型账户实测。

## 使用边界

- 草稿备份属于当前标签页。恢复时要求本机启动器可达并能确认项目身份。浏览器拒绝存储或空间不足时，编辑器保留本页内容并提示保存。
- 修改建议限已存在的单个 UTF-8 文本文件，原文和候选文本各限 24 KiB。提案模式在临时目录运行 Codex，使用其账户认证，忽略用户配置文件中的自定义模型提供方和工具设置。
- Codex 的原生续聊依赖云机上的会话记录。对应记录被清除时，可以查阅工作台已保存的问答输出并新建任务。该次验收使用的 Claude Code 任务为单轮问答。后续版本见 [Claude Code 续聊验收](validation-claude-conversations.md)。
