# 分别核对已暂存和未暂存的 Git 改动

在“Git 差异”打开“已暂存”和“未暂存（含未跟踪）”，可以看到将随下一次提交保存的内容，以及仍留在工作目录的修改。前一层比较 HEAD 和索引，后一层比较索引和工作文件，再列出可见的未跟踪文件。没有首个提交时也可读取已暂存的新文件。每一层先收到即可阅读。[工作进程回归](../tests/test_diff_scopes.py)

## 在 InstaBox 上复现

在同一份临时仓库中，把 `tracked.txt` 的一行从 `HEAD_A` 改为 `INDEX_B` 并暂存，再把工作文件改回 `HEAD_A`。云机 Git 2.47.3 报告 `MM tracked.txt`。旧版 `f2f626b3` 的 Chromium 界面显示“当前工作区没有 Git 差异”，合并补丁为 0 字节。

| 从标准工作台打开差异 | 已暂存 | 未暂存 |
| --- | --- | --- |
| 工作文件恢复为 HEAD | 显示 `HEAD_A → INDEX_B`，134 B | 显示 `INDEX_B → HEAD_A`，134 B |
| 工作文件继续改为 `WORK_C`，另建一个空文件 | 显示 `HEAD_A → INDEX_B` | 显示 `INDEX_B → WORK_C`，同时列出未跟踪的空文件 |
| 暂存一份过长的新增文件 | 独立截断到 65,536 B，并显示提示 | 完整显示 200 B |
| 保留一份过长的未跟踪文件 | 完整显示 134 B | 独立截断到 65,536 B |

浏览器在暂存层的一次请求上模拟断线，未暂存层仍可阅读。点“重试读取”只补发了暂存层。新版网页连接旧工作进程时，服务端忽略范围参数；浏览器只发一次探测并显示一个“合并差异”面板。[云机逐项记录](measurements/diff-layers.json)

## 阅读完整回包

每层按补丁正文的 UTF-8 字节数限制为 64 KiB。发送前若碰到有效字符的中间，会停在该字符之前。若内容超过上限，界面明确提示服务端截断，最后一个补丁块可能不完整。

在预算内，大量短行仍可能超过原有预览的 3,200 行上限。新版在每层本地按 800 行分页，可用页码直接到达末段。320 CSS 像素宽的 Chromium 实测中，两层分别收到 13,007 和 13,013 行，均分为 17 页，逐页内容及末行行号与原始回包一致。旧服务返回的一份截断补丁包含 21,705 行，收到的部分也可以分 28 页完整阅读。翻页不产生网络请求，另一层的页码及滚动位置保持不变。[浏览器回归](../tests/test_diff_scopes_ui.py)

另用 InstaBox 创建相同文件的两份长补丁，经工作台请求分别收到 11,007 和 11,014 行。在 320 CSS 像素宽的 Chromium 中，用键盘直达各自第 14 页，与云机回包核对末行及行号。打开和翻页合计只发出两次差异请求，每层一次。[云机浏览记录](measurements/diff-layers.json)

## 核对文件名、内容与执行位

可读取的未跟踪文本由已打开的普通文件描述符生成预览，不更改索引。回归使用原生 `git apply` 在另一临时仓库还原文件，核对了中文、控制字符和原始字节文件名、CRLF、无末行 LF、空文件及可执行脚本。旧接口仍返回合并补丁，未跟踪文件也使用修正后的正文、文件名和模式。已跟踪补丁的路径如果含有无法解码的字节，分层接口会让 Git 转义原始路径，以便区分实际的 U+FFFD 文件名与原始字节 FF。[未跟踪文件往返回归](../tests/test_untracked_diff.py)

InstaBox 实测还在独立目录应用了工作台返回的未跟踪补丁。还原文件的原始字节文件名、包含单个 CR 且不以 LF 结尾的正文和执行位均与源文件一致。

本机另外对照了普通重命名、`git mv` 后继续修改、`git add -N`、逐级忽略规则和合并冲突。已跟踪部分与同版本 Git 按相同选项生成的补丁一致。工作台保留 `--no-renames` 语义，重新命名会以删除和新增显示。二进制或超出预览上限的未跟踪文件仅列出路径。

## 回归

本机从独立源码快照运行 138 项回归，全部通过，零跳过。其中 49 项使用 Chromium，9 项使用原生模型 CLI。耗时 175.624 秒。[测试清单](measurements/regression-diff-layers.txt)

InstaBox 上运行了 84 项专项回归，其中 81 项通过。有 2 项系统 MCP 隔离用例需要 Bubblewrap，另有 1 项需要能创建相对登记路径工作树的 Git；云机未安装 Bubblewrap，Git 2.47.3 也不支持该创建选项，故跳过这 3 项。[云机测试范围及跳过原因](measurements/diff-layers.json)
